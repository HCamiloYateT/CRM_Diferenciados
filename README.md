# CRM Diferenciados

CRM independiente para la gestión downstream de exportación de café excelso diferenciado de Racafé. El alcance de proyecto exige `LinNegCod = 20000` original y evidencia del universo exportador.

`main` contiene la base documental. `desarrollo-inicial` reúne el diagnóstico y el diseño preliminar. La implementación comienza después de la Fase 1 y de la validación de los contratos que afecten cada módulo.
